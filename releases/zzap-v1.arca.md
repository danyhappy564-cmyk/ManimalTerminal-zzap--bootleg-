제목: [SPT 4.1] Manimal Terminal 0.2.20 zzap 수정 빌드 (한글화 · 렉 감소 · 유령 모드)

---

원작 Manimal Terminal 0.2.20 위에 덮어쓰는 비공식 수정 빌드입니다.
원작자 버전이 아니니 원작자분께 문의하지 말아 주세요. 바뀐 파일만 들어 있고 맵 번들은 원작 그대로 씁니다.

■ 무엇이 좋아졌나 (개발자 PC에서 터미널 한 판씩 잰 값)

- 레이드 시작 준비 멈춤: 7.2초 → 2.4초
- 1초 넘게 멈추는 횟수: 분당 2.7회 → 0.8회
- 터미널 모드 때문에 생긴 끊김: 판마다 약 20회 → 0~5회
- 유령 모드 켠 판 평균 프레임: 62fps → 65fps (하위 1% 34 → 43~48)
- 시민 떨림: 100프레임당 87~99회 → 0.4~0.7회 (다른 봇과 같음)

사양·모드 구성에 따라 다를 수 있습니다.

■ 바뀐 점

[한글화]
- 컷신 자막, 확성기 방송, 알림, 상호작용 버튼, 엔딩 화면, 퀘스트, 대화, 업적, 아이템
- F12 설정 이름과 설명 한글 표시 (게임 언어가 한국어가 아니면 영어로 나옴, 기존 설정값은 그대로 이어짐)

[안정성·성능]
- 레이드 시작·중간 렉 줄임, 레이드 끝나면 메모리 바로 반환
- LootInstantSearch(즉시 수색)와 같이 쓰면 튕기던 문제 수정
- SVM 커스텀 주머니에서 프라퍼 편지가 특수 슬롯에 안 들어가 입장이 막히던 문제 수정

[봇]
- RUAF: 터미널에서 플레이어의 총·수류탄 등 모든 공격에 무적, 계속 중립
  (F12 → 터미널 → "RUAF 무적(플레이어 피해)" 끄면 예전처럼 쏘는 순간 RUAF 전체가 적)
- 이벤트 스캐브가 뒤를 보고 걸어오던 문제, 등 뒤에서 맞아도 안 돌아보던 문제 수정
- 가까이 가도 안 보이다가 죽어야 보이던 봇 수정
- 시민이 몇 미터씩 순간이동하던 문제 수정
- 시민이 제자리에서 덜덜 떨던 문제: 원인이 시민 전용 애니메이션이라 기본으로 끔
  → 시민이 스캐브 기본 자세(주먹 쥔 자세)로 보입니다. F12에서 다시 켤 수 있지만 떨림이 돌아옵니다.

■ 유령 모드 (실험, 기본 꺼짐)

플레이어에게서 먼 분대를 재워 부담을 줄이는 기능입니다.
- 모든 플레이어에게서 125m 밖이면 잠들고 100m 안으로 오면 깹니다. 맞거나 스코프로 보면 바로 깹니다.
- 잠든 적 분대끼리는 숨은 채로 다가가 보이지 않는 곳에서 모의로 싸우고, 멀리서 총소리가 납니다. (한 판에 6~13번 정도)
- 켜는 법: F12 → Manimal-Terminal → 터미널 · 유령 모드 → "유령 모드 켜기"
- 켜면 화면 오른쪽 위에 상태 줄이 뜹니다. 같은 곳 "상태 표시"를 끄면 사라집니다.
- Fika(멀티)에서는 작동하지 않습니다.

■ 설치

1. 원작 Manimal Terminal 0.2.20이 깔려 있어야 합니다. (예전 zzap 테스트 빌드 위에도 그대로 덮어쓰면 됨)
2. 게임과 서버를 끕니다.
3. 혹시 몰라 BepInEx\plugins\ManimalTerminal, SPT_Runtime\user\mods\ManimalTerminal 두 폴더를 백업합니다.
4. 압축 안의 BepInEx, SPT_Runtime 폴더를 SPT 폴더(EscapeFromTarkov.exe 있는 곳)에 덮어씁니다.

■ 알려진 문제

- 봇이 처음 나타나는 순간 잠깐 끊길 수 있습니다 (게임 자체의 봇 초기화).
- 시민 전용 애니메이션을 다시 켜면 시민이 떨립니다.

문제가 생기면 백업한 폴더로 되돌리면 원래대로 돌아갑니다. 제보할 때 BepInEx\LogOutput.log 파일을 같이 올려 주시면 원인 찾기가 쉽습니다.
