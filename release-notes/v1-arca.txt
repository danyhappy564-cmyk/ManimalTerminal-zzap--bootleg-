Manimal Terminal zzap v1 — 한글화 · 렉 감소 · 유령 모드(먼 봇 재우기) 기본 켜짐

[구분선]

원작 Manimal Terminal 0.2.20 위에 덮어쓰는 수정 빌드입니다. 바뀐 파일만 들어 있고 맵은 원작 그대로 씁니다.

■ 고친 것

1) 한글화
- 이제: 게임 언어가 한국어면 컷신 자막, 확성기 방송, 알림, 상호작용 버튼, 엔딩 화면, 퀘스트, 대화, 업적, 아이템이 한국어로 나옵니다.
- F12 설정도 이름과 설명이 한글로 나옵니다. 게임 언어가 한국어가 아니면 영어로 나옵니다. 이미 바꿔 둔 설정값은 그대로 이어집니다.
- 확인: 개발자 게임에서 확인했습니다.

2) 레이드 시작·중간 렉
- 언제: 터미널 레이드가 시작될 때 화면이 몇 초씩 멈추고, 레이드 중에도 1초 넘게 멈추는 일이 잦았습니다.
- 왜: 맵 준비 작업 여러 개가 한 프레임에 몰려서 한꺼번에 돌았습니다.
- 이제: 준비 작업을 여러 프레임에 나눠서, 시작 준비 멈춤이 7.2초에서 2.4초로, 1초 넘게 멈추는 일이 분당 2.7번에서 0.8번으로 줄었습니다. 레이드가 끝나면 메모리도 바로 돌려줍니다.
- 확인: 개발자 PC에서 확인했습니다. 사양과 모드 구성에 따라 다를 수 있습니다.

3) 유령 모드 (먼 봇 재우기) — 기본 켜짐
- 무엇: 플레이어에게서 먼 분대의 AI를 재워서 부담을 줄이는 기능입니다.
- 어떻게: 모든 플레이어에게서 125m 밖이면 잠들고, 100m 안으로 오면 깹니다. 총에 맞거나 스코프로 들여다보면 바로 깹니다.
- 잠든 적 분대끼리는 숨은 채로 서로 다가가 안 보이는 곳에서 싸우고, 멀리서 실제 총소리가 납니다. 한 판에 6~13번 정도 일어나고, 평균 65프레임을 유지했습니다.
- 끄는 법: F12 → Manimal-Terminal → 터미널 · 유령 모드 → "유령 모드 켜기"를 끕니다. 화면 오른쪽 위 상태 줄은 같은 곳 "상태 표시"로 끌 수 있습니다.
- 멀티(Fika)에서는 작동하지 않습니다.
- 확인: 개발자 게임에서 여러 판 확인했습니다.

4) RUAF가 플레이어 공격에 무적
- 이제: 터미널에서 RUAF는 플레이어의 총·수류탄 등 모든 공격에 피해를 받지 않고 계속 중립입니다.
- 되돌리기: F12 → 터미널 → "RUAF 무적(플레이어 피해)"를 끄면, 예전처럼 한 명이라도 쏘는 순간 RUAF 전체가 적이 됩니다.
- 확인: 개발자 게임에서 확인했습니다.

5) 이벤트 스캐브가 등을 돌리고 걸어오던 문제
- 언제: 스캐브 이벤트 때 스캐브들이 뒤를 보며 걸어오고, 뒤에서 쏴도 돌아보지 않아 너무 쉽게 잡혔습니다.
- 왜: 돌진하는 동안 어디를 볼지 정해 주지 않아 처음 보던 방향을 계속 보고 있었고, 맞아도 돌진을 멈추지 않았습니다.
- 이제: 가는 방향을 보고 걸어오며, 맞으면 바로 전투로 넘어갑니다.
- 확인: 아직 게임에서 다시 확인하지 못했습니다.

6) 가까이 가도 안 보이다가 죽어야 보이던 봇
- 왜: 게임 자체에 멀리 있는 봇 몸을 숨기는 장치가 있는데, 유령 모드와 서로 몸 표시를 덮어쓰면서 숨김이 풀리지 않았습니다.
- 이제: 깨어나면 몸이 제대로 보이고, 잠든 봇이 굳은 채로 보이는 일도 없어졌습니다.
- 확인: 개발자 게임에서 확인했습니다.

7) 시민
- 순간이동: 시민이 가만히 있다가 몇 미터씩 순간이동하던 문제를 고쳤습니다. 확인했습니다.
- 떨림: 시민이 제자리에서 덜덜 떨던 원인이 시민 전용 동작이라 기본으로 껐습니다. 대신 시민이 스캐브 기본 자세(주먹 쥔 자세)로 보입니다. 끈 판에서 떨림이 다른 봇과 같은 수준으로 사라진 것을 확인했습니다.
- 다시 켜기: F12 → 터미널 → "시민: 전용 애니메이션" (떨림이 돌아옵니다)

8) 기타
- 즉시 수색 모드와 같이 쓰면 레이드 중 게임이 튕기던 문제 수정
- SVM 커스텀 주머니를 쓰면 프라퍼 편지가 특수 슬롯에 안 들어가 터미널 입장이 막히던 문제 수정
- 문제 찾기용 기록은 기본으로 껐습니다 (제보할 때만 F12에서 켜면 됩니다)

혹시 그래도 이상하면 설치 전에 백업한 폴더로 되돌리면 원래대로 돌아갑니다.

■ 설치

원작 Manimal Terminal 0.2.20이 깔려 있어야 합니다. 예전 zzap 테스트 빌드 위에도 그대로 덮어쓰면 됩니다.
1. 게임과 서버를 끕니다.
2. 혹시 몰라 BepInEx\plugins\ManimalTerminal, SPT_Runtime\user\mods\ManimalTerminal 두 폴더를 백업합니다.
3. Manimal-Terminal-0.2.20-zzap-v1.zip 풀어서 SPT 폴더에 덮어쓰기. 설정은 그대로 유지됩니다.
