## Manimal Terminal zzap v1

**- Korean localization · less stutter · Ghost Mode (sleeping distant bots) on by default**

■ Changes
- F12 settings follow your game language (English unless the game is in Korean); full Korean localization included
- Raid-start setup freeze 7.2 s → 2.4 s; freezes over 1 s went from 2.7 to 0.8 per minute (tested on the dev PC)
- Ghost Mode (on by default): squads beyond 125 m sleep to save performance; sleeping enemies fight out of sight and you hear it from afar (6–13 fights per raid, 65 fps average kept)
- RUAF: invulnerable to player attacks and stay neutral
- Fixed backwards-walking event scavs, bots invisible up close, teleporting civilians
- Civilians shaking in place: their retail animation (the cause) is now off, so they use the scav stance
- Fixed the crash with LootInstantSearch and SVM pockets refusing Prapor's letter

■ Install
- Requires the original Terminal 0.2.20
- Extract Manimal-Terminal-0.2.20-zzap-v1.zip into your SPT folder and overwrite (settings kept)

■ Notes
- Turn Ghost Mode off: F12 → Terminal · Ghost Mode → untick "Ghost Mode on". Not for Fika
- Please don't contact the original author about this build
