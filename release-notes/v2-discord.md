## Manimal Terminal zzap v2

**- 다른 맵을 끝낸 뒤 메뉴에서 메모리가 남던 것 수정 (v1 내용은 그대로)**

■ 바뀐 것
- 터미널이 아닌 맵(리저브·세관 등)을 끝낸 뒤 그 맵의 날씨 정보가 메뉴에서도 메모리에 남던 것 수정 — RAM 클리너 누수 보고에 터미널 모드가 나오던 원인 (게임 시뮬 3판에서 누수 목록에서 사라진 것 확인)
- ORBIT 라이선스 원문을 압축에 포함

■ 설치
- 원본 터미널 0.2.20을 먼저 받아 설치해야 작동 (이 압축엔 맵 없음): <https://pub-38fba86cac60421ebd03a218d2535c13.r2.dev/Manimal-Terminal-SPT-4.1-0.2.20.zip>
- Manimal-Terminal-0.2.20-zzap-v2.zip 풀어서 SPT 폴더에 덮어쓰기 (설정 유지, v1에서는 파일 하나만 바뀜)

■ 주의
- 터미널 맵 자체는 v1과 같은 코드라 다시 돌려 보지 않았습니다
- 원작자분께 문의하지 말아 주세요
